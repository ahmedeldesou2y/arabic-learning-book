# Arabic Learning Companion App
## التطبيق التفاعلي المصاحب لكتاب تعلم اللغة العربية

### Overview | نظرة عامة
An interactive web-based companion application designed to assist Arabic language learners. The application provides audio pronunciations and interactive exercises to enhance the learning experience, serving as a digital extension to the physical book.

تطبيق ويب تفاعلي مصمم لمساعدة متعلمي اللغة العربية. يوفر التطبيق نطقاً صوتياً وتدريبات تفاعلية لتعزيز تجربة التعلم، ويعمل كامتداد رقمي للكتاب المطبوع.

### Features | المميزات
* **Audio Pronunciation:** Clickable elements that play corresponding Arabic audio files to ensure correct pronunciation.
* **Interactive Exercises:** Engaging activities and assessments linked directly to the book's curriculum.
* **Optimized Performance:** Obfuscated source code for security and structured audio asset management to prevent audio overlap.

* **نطق صوتي:** عناصر تفاعلية تقوم بتشغيل ملفات صوتية عربية عند النقر عليها لضمان النطق الصحيح.
* **تدريبات تفاعلية:** أنشطة وتقييمات تفاعلية مرتبطة مباشرة بمنهج الكتاب.
* **أداء محسن:** كود برمجي محمي، وتنظيم هيكلي لملفات الصوت يمنع تداخل المقاطع الصوتية أثناء التشغيل.

### Technologies Used | التقنيات المستخدمة
* HTML5
* CSS3
* Vanilla JavaScript
